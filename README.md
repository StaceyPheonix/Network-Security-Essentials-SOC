# Network Security Essentials for SOC Analysts

## Overview

This repository documents fundamental networking concepts and their application within Security Operations Center (SOC) environments.

Understanding how systems communicate is essential for analyzing alerts, investigating suspicious activity, and identifying potential threats. This project focuses on the networking knowledge required to support security monitoring, threat detection, and incident response.

## Objectives

* Build foundational networking knowledge used in security operations
* Understand how common protocols and services communicate
* Recognize normal versus abnormal network behavior
* Apply networking concepts during SOC investigations
* Develop an analyst-focused reference for network security concepts

## Topics Covered

* OSI Model and TCP/IP Model
* TCP vs. UDP
* Common Network Protocols
* Well-Known Ports and Services
* DNS Fundamentals and Security Considerations
* DHCP
* NAT
* Firewalls
* Network Segmentation
* Packet Flow
* Network Monitoring Fundamentals

## SOC Analyst Applications

Networking knowledge supports many common SOC investigations, including:

### Suspicious Network Traffic

* Reviewing source and destination communication
* Identifying unusual connections
* Understanding expected network behavior
* Investigating abnormal traffic patterns

### Malware Investigation

* Identifying command-and-control (C2) communication
* Investigating suspicious DNS activity
* Recognizing potential beaconing behavior
* Reviewing network indicators of compromise (IOCs)

### Internal Threat Detection

* Investigating possible lateral movement
* Understanding SMB and remote access activity
* Reviewing unexpected internal communication

### Security Monitoring

* Understanding firewall and network logs
* Supporting alert triage
* Investigating network-based indicators
* Providing context during incident response

## Repository Contents

* Networking fundamentals

## Key Takeaways

Networking fundamentals are the foundation of effective security monitoring. A SOC analyst must understand how systems communicate in order to identify abnormal behavior, investigate alerts, and determine whether activity represents normal operations or a potential security incident.
